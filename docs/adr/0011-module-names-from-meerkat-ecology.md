# ADR-0011: モジュールの名前をミーアキャットの生態から採る

## ステータス

Proposed (2026-09-12)

## 背景

交換の設計([ADR-0009](0009-record-exchange-transport.md))が固まり、構成が2つのモジュールに
分かれることが見えた。

1. 各機械に常駐し、発話と聞こえを記録し、異常に気づいて知らせるもの
2. エージェント同士が**名刺**(身元、公開鍵、現在の宛先)を交換する場

現在の名前は `MeerkatsCore` と `MeerkatsAgent` である。`Agent` は役割を何も言っていない。
2つ目が加わると「Agentと、もう一つの何か」になり、**対になっていない名前が2つ並ぶ。**

リポジトリ名が `meerkats-hear-you` である以上、生態から採るのが素直。

## 決定(提案)

| モジュール | 名前 | 生態上の由来 |
|---|---|---|
| 記録と気づき | **MeerkatsSentry** | 見張り。群れが採餌する間、1頭が塚などの高所で後ろ足立ちになって周囲を見張る。脅威の種類によって鳴き分ける |
| 名刺の交換 | **MeerkatsBurrow** | 巣穴。ミーアキャットの巣穴はキイロマングースやケープジリスなど他種と共有され、食物でも空間でも競合しない共存関係になっている |

### MeerkatsSentry

見張りの本体は記録ではなく、**気づいて知らせること**にある。要望書の「指摘されずとも気づける」
そのものである。空からの脅威と地上の脅威で鳴き分ける行動は、異常の種類で通知を分ける
([ADR-0008](0008-process-tap-for-received-audio.md))ことに対応している。

**MeerkatsBurrowと対になる。** 見張るのがSentry、集うのがBurrow、身を隠すのが
[Bolthole](0010-recording-floor-broadband-only.md)。どれもミーアキャットの一日に出てくる営みであり、
**関係が名前に残る。**

### MeerkatsBurrow

巣穴は自分の住処であると同時に、**他の群れや他種が出入りする場所**でもある。名刺交換の場として、
この「自分のものだが自分だけのものではない」性質が合う。

**実装がどの形になっても名前が保つ。** ADR-0009では運用するサーバを持たず、名刺を作って読む
ローカルの部品になるが、後でランデブーを置いてもMeerkatsBurrowのままでよい。

## 採用しなかった案

- **Mound (塚)。** 見張りが登る場所。製品名との衝突は無く、一時はこちらを採っていた。ただし
  **場所であって役割ではなく、何をするモジュールなのかが読み取りにくい。** 接頭辞で衝突が解けるなら、
  生態の語として正確なSentryのほうがよい。
- **Lookout。** 通俗的な説明では見張り役をこう呼び、機能も読んで分かる。ただしモバイル警備の
  製品名がある。
- **Kopje (コッピー)。** サバンナの岩山で、ミーアキャットが見張りにも隠れ家にも使う。衝突は無いが、
  単純に連想される語とは言えない。
- **Sunning (日光浴)。** 朝の日光浴中の鳴き交わしは「直接接触せずに社会的つながりを保つ」
  behaviourで、意味としては交換にかなり近い。ただし場ではなく行動であり、名刺交換の「場」には
  ならない。惜しいが採らない。
- **Roving (放浪)。** 若いオスが他の群れを訪ねる行動。移動する主体を指すので、場の名前にならない。
- **役割をそのまま英語にする (Recorder / Exchanger)。** 分かりやすいが、どのプロジェクトにも
  ある名前になる。生態から採る利点は**関係が名前に残ること**にあり、見張りと巣穴は同じ群れの
  営みの一部だが、RecorderとExchangerにはその関係が無い。

### 接頭辞を付ける

`Meerkats` を前に置く。**ドメインの用語であることが名前から分かる。** `MeerkatsCore` が既に
その形になっており、揃う。`Sentry` や `Burrow` は英語の普通名詞でもあるため、接頭辞が無いと
一般語と見分けがつかない。

**接頭辞は製品名との衝突も解く。** `Sentry` 単体ではSaaSのsentry.ioと紛れる。しかも紛れ方が悪く、
異常を監視して通知を出すという中身まで似ている。`MeerkatsSentry` なら紛れない。

記録の水準を指す `Bolthole` は型でもターゲットでもなく文章中で使う語なので、接頭辞は付けない。

## 影響

- `MeerkatsAgent` を `MeerkatsSentry` に改名する。**バンドルには影響しない。** `build.sh` は
  SPMの製品名をビルド成果物の場所を特定するためだけに使い、`.app` 内の実行ファイルは
  `Meerkats` 固定である。バンドルIDも実行ファイル名も変わらないため、**TCCの許可は失われない**
  ([ADR-0008](0008-process-tap-for-received-audio.md))。
- `MeerkatsCore` は両方から使う純粋ロジックなので、そのまま。
- 改名はソースの移動だけで、ロジックは1行も動かない。CIが通ることで確かめられる。
