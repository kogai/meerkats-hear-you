# ADR-0005: エージェントとUIを単一のメニューバー常駐アプリとして構成する

## ステータス

Proposed

## 背景

要望書は構成要素として「エージェント」「常時表示UI」「分析UI」を挙げている。これらを別プロセスに
分ける構成(例: launchdデーモンがキャプチャを担い、UIアプリが表示を担う)も考えられる。

ただしmacOSのマイク・画面収録の権限(TCC)はアプリ単位で付与される。プロセスを分けると、
キャプチャを行う側が権限を持つ必要があり、利用者から見て「何に許可を与えているのか」が
わかりにくくなる。また常時表示UIは本質的に常駐プロセスの状態表示であり、両者を分ける動機が弱い。

## 決定

単一の `.app` として実装し、メニューバーに常駐させる(LSUIElement指定、Dockアイコンなし)。
キャプチャ・解析・記録・常時表示・分析UIをすべてこのプロセスが担う。

## 影響

- 権限の付与対象がこのアプリ1つに閉じ、利用者から見てわかりやすい。
- 常時表示は、メニューバー項目に現在のレベルと状態を出す形になる。
- 分析UIはメニューから開くウインドウとして実装する。
- **UIが落ちると記録も止まる。** プロセスを分けていれば記録だけは継続できたが、その利点は
  権限まわりの単純さと引き換えに手放す。
- 常駐が前提のため、ログイン時の自動起動が必要になる。
