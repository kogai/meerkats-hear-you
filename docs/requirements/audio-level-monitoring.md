# 要望書: オンラインセッション向け音声レベル記録・分析ツール

## 背景・課題

- オンラインセッションで音が聞き取りづらいと言われることがある。
- OSデフォルトの機能だとリアルタイム表示しかないので、どういう問題があるのか類推しづらい。
- ハードなのか、ソフトなのか、ネットワークなのか、切り分けができない。

## やりたいこと

- 発話と音声レベルを表示・記録して、指摘されずとも聞き取りづらくなってたら気づける、指摘されたらどこがどのように聞き取りづらかったのか振り返れる、分析できる、ような仕組みを作りたい。

## 要件

- なるべくネットワーク、ハードウェア不可知な、記録が欲しい。
- 聞き取りづらいと言われてるのに記録上は正常となると作る意味が皆無になる。
- 発話と相手側の聞こえ方を突合出来るようにもしたほうがいいだろう。
  - その場合は相手にも同じようにエージェントを常駐させてよい。
- おそらくエージェントと、エージェントからのデータを常時表示するUI、分析UI、からなるだろう。

## プライバシー・データの取り扱い

- 機微な内容もあるだろうから内容録音とかはしないし、音声レベル以外には興味をもたない、復元もできないのがよい。
- そもそもクラウドにデータを送らない。
- データのやり取りがどうしても必要なら、システムを迂回して人間に送ってもらうか、エージェント同士のP2Pにする。ただしP2Pでも暗黙に送ることはNG。
