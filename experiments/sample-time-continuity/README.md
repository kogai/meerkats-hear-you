# サンプル時刻の連続性(実機)

[ADR-0015](../../docs/adr/0015-frame-count-with-clock-resync.md) が「確かめること」に
残した項目を潰すためのスパイク。**Mac の実機でしか走らない。**

## なぜ要るか

ADR-0015 は、**途切れたと分かっている事象**でだけ記録の基準を打ち直すと決めた。
最初のバッファ、停止からの再開、デバイスの差し替え——どれもこちらが知っている。

知らない場合が1つ残る。**エンジンが走ったまま、過負荷でバッファが飛んだとき**である。
こちらの知っている事象は何も起きないので、打ち直しも空隙の記録も起きない。
取りこぼした区間が、記録の上では「静かだった」と読めることになる。

拾える見込みがあるのは、音声層が報告するサンプル時刻の不連続だけである。
**それが実際に取れるかどうかを、まだ確かめていない。**

## 実行方法

```bash
mise run sample-time
```

または直接:

```bash
cd experiments/sample-time-continuity
swift run SampleTimeSpike
```

40秒ぶんのバッファを集めます。途中で **1秒・4秒・12秒** と長さを変えて3回詰まらせ、
落ちたぶんがサンプル時刻の飛びとして現れるかを見ます。

- 初回はマイクの許可を求められます。許可してください
- 何か音を出しながら走らせる必要はありません。無音でもサンプル時刻は進みます

**1回・0.8秒だった前の版では、何も落ちませんでした。** 下の「1回目の結果」を参照。

## 見るところ

出力の3節が、そのまま ADR-0015 の「確かめること」に対応しています。

**1. サンプル時刻は取れるか** — `isSampleTimeValid` が全バッファで true なら取れています。
false が混ざるなら、この手は使えません。

**2. 落ちたバッファは飛びとして現れるか** — ここがいちばん知りたいところです。

**結果は3つに分かれます。** 前の版は上2つを1つにまとめていて、区別できていませんでした。

- **飛びが出た** → 未知の取りこぼしを拾えます。ADR-0015 の `RecordingGap.Reason` に
  1つ足して、実装に入れます
- **飛びは無いが、勘定の合わない差がある** → 落ちているのに見えていません。
  この手では拾えないので、**ADR-0015 を書き換えます**(未知の取りこぼしは
  検出できないものとして扱う形に)
- **飛びも無く、勘定も合っている** → **そもそも落ちていません。** 詰まらせたぶんは
  溜められて後から届いています。この回は何も確かめていないので、詰まらせを長くします

「勘定の合わない差」は、到着から見た窓の長さと、サンプル時刻が張る幅の差です。
窓のほうが長ければ、その差は届かなかった音です。

**3. ホストタイムはどちらの基数か** — 絶対時刻との差が小さく、連続時刻との差が大きければ
中断側です。その場合、ADR-0003 が指定する連続単調時計へ移すには、到着ごとに両方を
読んで差を取る必要があります。

**一度もスリープしていない機械では、どちらの差も同じに見えます。** 差が出なかったら、
蓋を閉じて開けてからもう一度走らせてください。

## 受信側について

**このスパイクはマイク側だけを見ます。** 受信側(Core Audio のプロセスタップ)は
組み立てが長く、ここに写すと確かめたいことより写し間違いのほうが多くなります。

1〜3 が取れると分かってから、同じ形で受信側に足します。そのとき追加で確かめるのは
**2本のサンプル時刻が同じ基数に乗っているか**で、これは ADR-0012 の突合に効きます。

## 結果 (2026-09-24)

**3つとも片付いた。** 詳細は [`docs/experiments/sample-time-continuity-result.md`](../../docs/experiments/sample-time-continuity-result.md)。

| | 結果 |
|---|---|
| 1. サンプル時刻は取れるか | 取れる。全バッファで `isSampleTimeValid`、`frameLength` は 4800 固定 |
| 2. 落ちたぶんは飛びとして出るか | **出る。** 4秒の詰まらせで 2.500 秒、12秒で 10.500 秒 |
| 3. ホストタイムの基数 | **中断側** (`mach_absolute_time`)。連続時刻との差は 9.36日 |

**副産物: タップは約1.5秒ぶん抱える。** 詰まらせた長さから落ちた長さを引くと、4秒でも12秒でも
1.5秒になる。1秒の詰まらせでは1つも落ちない。

**1回目(1回・0.8秒の版)は何も落とせていなかった。** 149バッファ = 14.900秒で窓の15秒を
ほぼ埋めており、1.5秒に届いていない。それなのに出力は「この手では拾えない」と読んだ。
取りこぼしの有無を数えていなかったためで、いまの版は数える。
